# Rust 예시 프로젝트 - 무엇을 만들어 보면 좋을까

## 들어가며

문법을 익혔다면 직접 무언가를 만들어 봐야 합니다. Rust는 특히 아래 특성이 필요한 분야에서 강점을 보입니다.

```
Rust 가 빛나는 곳
✅ 성능이 중요하지만 C/C++ 의 메모리 버그는 피하고 싶을 때
✅ 단일 바이너리로 배포하고 싶을 때 (런타임/VM 설치 불필요)
✅ 시작 속도와 메모리 사용량이 중요할 때 (CLI, 서버리스, 임베디드)
✅ 동시성/병렬 처리가 많을 때
✅ 다른 언어(JS, Python)의 느린 부분을 대체할 때 (napi-rs, PyO3, WASM)

Rust 가 과할 수 있는 곳
⚠️ 빠르게 프로토타입을 만들어야 하는 CRUD 웹앱 (생산성은 TS/Python/Rails 가 유리)
⚠️ 팀이 Rust 를 모르고 러닝 커브를 감당하기 어려울 때
⚠️ 컴파일 시간이 개발 흐름에 크게 방해되는 경우
```

아래 프로젝트들은 **난이도 순서**로 정리했고, 각각 왜 Rust가 적합한지, 어떤 크레이트를 쓰면 좋은지, 참고할 실제 오픈소스를 함께 적었습니다.

## 1-3. 할 일 관리 CLI (Todo)

JSON 파일에 할 일을 저장/조회/완료 처리하는 CLI입니다.

```bash
todo add "러스트 공부하기"
todo list
todo done 1
```

- 배우는 것: 구조체/enum 모델링, 직렬화, 서브커맨드 파싱
- 크레이트: `clap` (derive), `serde` + `serde_json`, `anyhow`, `chrono`
- 참고: clap derive 튜토리얼 https://docs.rs/clap/latest/clap/_derive/_tutorial/index.html

```rust
// (컴파일 검증: 외부 크레이트) clap 4 (derive) 뼈대 예시
use clap::{Parser, Subcommand};

#[derive(Parser)]
#[command(name = "todo", version, about = "간단한 할 일 관리")]
struct Cli {
    #[command(subcommand)]
    command: Command,
}

#[derive(Subcommand)]
enum Command {
    /// 할 일 추가
    Add { title: String },
    /// 목록 보기
    List {
        #[arg(short, long)]
        all: bool,
    },
    /// 완료 처리
    Done { id: usize },
}

fn main() {
    let cli = Cli::parse_from(["todo", "add", "러스트 공부하기"]); // 실제로는 Cli::parse()
    match cli.command {
        Command::Add { title } => println!("추가: {title}"),
        Command::List { all } => println!("목록 (all={all})"),
        Command::Done { id } => println!("{id}번 완료"),
    }
}
```

# 3. 중급 (웹, 비동기, WASM)

## 3-1. REST API 서버 (axum)

게시판, 단축 URL, 할 일 API 등. Rust 백엔드의 표준 조합을 익힙니다.

- 왜 Rust: 낮은 지연 시간과 메모리 사용, 컴파일 타임 타입 안전성, 적은 서버 비용
- 크레이트: `axum`, `tokio`, `serde`, `sqlx`(PostgreSQL/SQLite, 컴파일 타임 쿼리 검사) 또는 `sea-orm`, `tower-http`(CORS, 로깅), `tracing`, `jsonwebtoken`, `argon2`, `validator`
- 참고할 오픈소스
  - axum 공식 예제 모음: https://github.com/tokio-rs/axum/tree/main/examples
  - RealWorld 앱 (axum + sqlx): https://github.com/launchbadge/realworld-axum-sqlx
  - Rails 스타일 풀스택 프레임워크 loco: https://github.com/loco-rs/loco
- 책: Zero To Production In Rust https://www.zero2prod.com

```rust
// (컴파일 검증: 외부 크레이트) axum 0.8 + tokio + serde 최소 예시
use axum::{
    Json, Router,
    extract::{Path, State},
    http::StatusCode,
    routing::get,
};
use serde::{Deserialize, Serialize};
use std::sync::{Arc, Mutex};

#[derive(Clone, Serialize, Deserialize)]
struct Todo {
    id: u64,
    title: String,
    done: bool,
}

#[derive(Deserialize)]
struct CreateTodo {
    title: String,
}

type Db = Arc<Mutex<Vec<Todo>>>;

async fn list(State(db): State<Db>) -> Json<Vec<Todo>> {
    Json(db.lock().unwrap().clone())
}

async fn create(State(db): State<Db>, Json(input): Json<CreateTodo>) -> (StatusCode, Json<Todo>) {
    let mut todos = db.lock().unwrap();
    let todo = Todo { id: todos.len() as u64 + 1, title: input.title, done: false };
    todos.push(todo.clone());
    (StatusCode::CREATED, Json(todo))
}

async fn get_one(State(db): State<Db>, Path(id): Path<u64>) -> Result<Json<Todo>, StatusCode> {
    db.lock()
        .unwrap()
        .iter()
        .find(|t| t.id == id)
        .cloned()
        .map(Json)
        .ok_or(StatusCode::NOT_FOUND)
}

fn app() -> Router {
    let db: Db = Arc::new(Mutex::new(vec![]));
    Router::new()
        .route("/todos", get(list).post(create))
        .route("/todos/{id}", get(get_one)) // axum 0.8 부터 경로 매개변수는 {id}
        .with_state(db)
}

#[tokio::main]
async fn main() {
    let listener = tokio::net::TcpListener::bind("127.0.0.1:3000").await.unwrap();
    println!("http://127.0.0.1:3000/todos");
    axum::serve(listener, app()).await.unwrap();
}
```

## 3-3. WebAssembly로 브라우저에서 Rust 실행

JS로 무거운 계산(이미지 처리, 게임 로직, 시뮬레이션, 파서)을 Rust로 옮기는 프로젝트입니다.

- 왜 Rust: GC가 없어서 WASM 바이너리가 작고, JS 대비 계산 성능이 좋음
- 크레이트/도구: `wasm-bindgen`, `wasm-pack`, `web-sys`, `js-sys`
- 첫 프로젝트: 콘웨이의 생명 게임
  - 영문: https://rustwasm.github.io/docs/book/game-of-life/introduction.html
  - 한국어 번역: https://wasm.rust-kr.org/game-of-life/introduction.html
- 풀스택 Rust 웹 프레임워크: [Leptos](https://github.com/leptos-rs/leptos), [Dioxus](https://github.com/DioxusLabs/dioxus), [Yew](https://github.com/yewstack/yew)

```rust
// (컴파일 검증 제외) - wasm-pack 프로젝트 필요
use wasm_bindgen::prelude::*;

#[wasm_bindgen]
pub fn fib(n: u32) -> u64 {
    let (mut a, mut b) = (0u64, 1u64);
    for _ in 0..n {
        (a, b) = (b, a + b);
    }
    a
}
```

```js
// 번들러(Vite 등)에서
import init, { fib } from "./pkg/my_wasm.js";
await init();
console.log(fib(50));
```

# 6. 추천 학습 경로

```
1주차   숫자 맞히기 → minigrep → Rustlings
2~3주차  Todo CLI (clap + serde) → bat/fd 축소판
4~6주차  axum REST API + sqlx → 채팅 서버
이후     관심 분야 선택
         - 웹 프론트: WASM 생명 게임 → Leptos
         - 데스크톱: Tauri 앱
         - 게임: Bevy 벽돌 깨기
         - 시스템: 인터프리터, KV 저장소, OS 튜토리얼
         - 하드웨어: Embassy + Pico/ESP32
```

## 정리

- 입문은 러스트 북 프로젝트(숫자 맞히기, minigrep)와 Rustlings로 시작
- CLI/TUI 도구는 Rust의 장점(속도, 단일 바이너리)이 가장 잘 드러나는 첫 실전 분야
- 웹 백엔드는 axum + tokio + sqlx, 프론트/브라우저는 WASM, 데스크톱은 Tauri
- 게임(Bevy), 인터프리터, DB, OS, 임베디드는 Rust의 강점을 깊게 체감할 수 있는 고급 주제
- 유명 오픈소스 코드를 읽으며 관용적인 스타일을 익히자
