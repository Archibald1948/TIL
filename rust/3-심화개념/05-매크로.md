# 매크로 - 코드를 생성하는 코드

## 들어가며

`println!`, `vec!`, `#[derive(Debug)]`, `#[tokio::main]`... 지금까지 매크로를 계속 써왔습니다. 매크로는 **컴파일 타임에 코드를 생성하는 코드**(메타프로그래밍)입니다.

```
함수                                  매크로
- 매개변수 개수, 타입이 고정            - 가변 개수 인자 가능 (println!("{} {}", a, b))
- 런타임에 호출                        - 컴파일 타임에 코드로 전개
- 트레이트 구현 생성 불가               - impl 블록, 구조체 등 아이템 생성 가능
- 읽기/디버깅 쉬움                     - 읽기/디버깅 어려움 → 함수로 되면 함수를 쓰자
```

Rust 매크로는 C의 `#define` 같은 텍스트 치환이 아니라 **토큰 트리(구문 구조)**를 다루므로 훨씬 안전합니다.

```
매크로 종류
1. 선언적 매크로 (declarative)  macro_rules! { 패턴 => 코드 }
2. 절차적 매크로 (procedural)   Rust 코드로 토큰을 입력받아 토큰을 출력
   - derive 매크로          #[derive(MyTrait)]
   - 속성(attribute) 매크로  #[route(GET, "/")]
   - 함수형 매크로           sql!(SELECT * FROM users)
```

# 1. 선언적 매크로 macro_rules!

## 기본 형태

```rust
macro_rules! say_hello {
    // () => { ... }  : 인자가 없는 패턴
    () => {
        println!("Hello!");
    };
    // $name:expr : 표현식 하나를 받아 $name 에 바인딩
    ($name:expr) => {
        println!("Hello, {}!", $name);
    };
}

fn main() {
    say_hello!();
    say_hello!("Rust");
    say_hello!(1 + 2);
}
```

`match`처럼 **위에서부터 패턴을 비교**해서 처음 맞는 갈래를 전개합니다. 호출할 때는 `()`, `[]`, `{}` 중 아무 괄호나 쓸 수 있습니다 (`vec![]`, `println!()`은 관례).

## 프래그먼트 지정자

| 지정자 | 매칭 대상 | 예 |
|---|---|---|
| `expr` | 표현식 | `1 + 2`, `foo()` |
| `ident` | 식별자 | `x`, `my_fn` |
| `ty` | 타입 | `i32`, `Vec<String>` |
| `pat` | 패턴 | `Some(x)`, `1..=5` |
| `stmt` | 문 | `let x = 1` |
| `block` | 블록 | `{ ... }` |
| `item` | 아이템 | `fn f() {}`, `struct S;` |
| `path` | 경로 | `std::collections::HashMap` |
| `literal` | 리터럴 | `42`, `"hi"` |
| `lifetime` | 라이프타임 | `'a` |
| `meta` | 속성 내용 | `derive(Debug)` |
| `tt` | 토큰 트리 하나 (무엇이든) | |

## 반복: $( ... ),*

```rust
// vec! 을 직접 만들어보기
macro_rules! my_vec {
    () => {
        Vec::new()
    };
    // $( $x:expr ),* : 쉼표로 구분된 표현식 0개 이상
    // $(,)?          : 마지막 쉼표 허용
    ( $( $x:expr ),* $(,)? ) => {{
        let mut v = Vec::new();
        $(
            v.push($x); // 매칭된 개수만큼 반복 전개
        )*
        v
    }};
}

fn main() {
    let empty: Vec<i32> = my_vec![];
    let v = my_vec![1, 2, 3,];
    println!("{empty:?} {v:?}");
}
```

```
반복 연산자
$( ... ),*   → 0회 이상, 쉼표 구분
$( ... );+   → 1회 이상, 세미콜론 구분
$( ... )?    → 0 또는 1회
```

`my_vec![1, 2, 3]`은 컴파일 타임에 다음과 같이 전개됩니다.

```rust
fn main() {
    let v = {
        let mut v = Vec::new();
        v.push(1);
        v.push(2);
        v.push(3);
        v
    };
    println!("{v:?}");
}
```

## 실용 예제: HashMap 리터럴

```rust
use std::collections::HashMap;

macro_rules! hashmap {
    ( $( $key:expr => $value:expr ),* $(,)? ) => {{
        let mut map = HashMap::new();
        $( map.insert($key, $value); )*
        map
    }};
}

fn main() {
    let scores = hashmap! {
        "kim" => 90,
        "lee" => 85,
    };
    println!("{:?}", scores.get("kim"));
}
```

## 아이템 생성: 반복되는 impl 줄이기

```rust
trait Describe {
    fn describe() -> String;
}

macro_rules! impl_describe {
    ( $( $t:ty => $name:literal ),+ ) => {
        $(
            impl Describe for $t {
                fn describe() -> String {
                    format!("{} ({}바이트)", $name, std::mem::size_of::<$t>())
                }
            }
        )+
    };
}

impl_describe!(u8 => "부호 없는 8비트", i64 => "부호 있는 64비트", f32 => "32비트 실수");

fn main() {
    println!("{}", u8::describe());
    println!("{}", i64::describe());
    println!("{}", f32::describe());
}
```

표준 라이브러리도 정수 타입마다 같은 메서드를 구현할 때 이런 매크로를 사용합니다.

## 식별자로 구조체와 메서드 생성

```rust
macro_rules! make_struct {
    ($name:ident { $( $field:ident : $ty:ty ),* $(,)? }) => {
        #[derive(Debug, Default)]
        struct $name {
            $( $field: $ty ),*
        }

        impl $name {
            fn field_names() -> Vec<&'static str> {
                vec![ $( stringify!($field) ),* ]
            }
        }
    };
}

make_struct!(User { id: u64, name: String, active: bool });

fn main() {
    let u = User { id: 1, name: "kim".into(), active: true };
    println!("{u:?}");
    println!("{:?}", User::field_names());
    println!("{:?}", User::default());
}
```

## 재귀 매크로

```rust
// 인자 개수 세기 (컴파일 타임)
macro_rules! count {
    () => { 0usize };
    ($head:tt $($tail:tt)*) => { 1usize + count!($($tail)*) };
}

// 최댓값
macro_rules! max {
    ($x:expr) => { $x };
    ($x:expr, $($rest:expr),+) => {{
        let a = $x;
        let b = max!($($rest),+);
        if a > b { a } else { b }
    }};
}

fn main() {
    const N: usize = count!(a b c d);
    println!("{N}");
    println!("{}", max!(3, 9, 2, 7));
}
```

## 위생성 (Hygiene)

```rust
macro_rules! using_a {
    ($e:expr) => {{
        let a = 42; // 매크로 내부의 a
        $e          // 호출자가 넘긴 표현식
    }};
}

fn main() {
    let a = 1;
    // 매크로 안의 a 와 호출자의 a 는 서로 다른 변수로 취급됨
    let result = using_a!(a * 10);
    println!("{result}"); // 10 (42*10 이 아님)
}
```

C 매크로처럼 변수 이름이 우연히 충돌하는 문제가 없습니다.

## 매크로 내보내기와 디버깅

```rust
// (컴파일 검증 제외) - 크레이트 구조 예시

// src/lib.rs
#[macro_export] // 크레이트 루트에 공개됨: 다른 크레이트에서 my_crate::my_vec! 로 사용
macro_rules! my_vec {
    ( $( $x:expr ),* ) => { vec![ $( $x ),* ] };
}

// 매크로 안에서 같은 크레이트의 아이템을 참조할 땐 $crate 사용
#[macro_export]
macro_rules! new_point {
    ($x:expr, $y:expr) => {
        $crate::Point { x: $x, y: $y }
    };
}
```

# 2. 자주 쓰는 표준 매크로

```rust
fn main() {
    let v = vec![1, 2, 3];
    let s = format!("{v:?}");
    println!("{s}");
    eprintln!("stderr");

    assert!(v.len() == 3, "길이가 3이어야 함");
    assert_eq!(v[0], 1);
    debug_assert!(v.iter().all(|&x| x > 0)); // 릴리스 빌드에서는 제거됨

    let x = dbg!(v.len() * 2); // stderr 에 "[src/main.rs:줄:열] v.len() * 2 = 6" 출력 후 값 반환
    println!("{x}");

    println!("{}", stringify!(a + b * c));        // "a + b * c" (코드를 문자열로)
    println!("{}:{}", file!(), line!());          // 현재 파일, 줄
    println!("{}", concat!("rust", "-", 2024));   // 컴파일 타임 문자열 연결
    println!("{}", env!("CARGO_PKG_NAME", "cargo 로 빌드하지 않음")); // 컴파일 타임 환경 변수 (없으면 컴파일 에러)
    println!("{:?}", option_env!("NOT_SET_VAR")); // 없으면 None

    // include_str!("../README.md")  → 파일 내용을 &'static str 로 바이너리에 포함
    // include_bytes!("logo.png")    → &'static [u8; N]

    if v.is_empty() {
        unreachable!("비어있을 수 없음");
    }
    let _later = || -> i32 { todo!("나중에 구현") };
    let _never = || -> i32 { unimplemented!() };

    let ok = matches!(v.first(), Some(&n) if n == 1);
    println!("{ok}");

    let mut out = String::new();
    use std::fmt::Write;
    write!(out, "{}-{}", 1, 2).unwrap();
    println!("{out}");
}
```

`env!("CARGO_PKG_NAME")`은 cargo가 빌드할 때 설정하는 환경 변수라서 `rustc`로 직접 컴파일하면 에러가 납니다. 위 예제는 cargo 프로젝트에서 실행하세요.

# 3. 절차적 매크로 (Procedural Macros)

절차적 매크로는 **별도의 크레이트**(`proc-macro = true`)에 정의해야 하며, `TokenStream`을 받아 `TokenStream`을 반환하는 함수입니다. 보통 `syn`(파싱)과 `quote`(코드 생성) 크레이트를 함께 씁니다.

```
my_project/
├── Cargo.toml          (workspace)
├── hello_macro/        일반 라이브러리: 트레이트 정의
├── hello_macro_derive/ proc-macro 크레이트: derive 구현
└── app/                사용하는 쪽
```

## derive 매크로 만들기

```toml
# hello_macro_derive/Cargo.toml
[package]
name = "hello_macro_derive"
version = "0.1.0"
edition = "2024"

[lib]
proc-macro = true

[dependencies]
syn = "2"
quote = "1"
```

```rust
// (컴파일 검증: 별도 proc-macro 크레이트) hello_macro_derive/src/lib.rs
use proc_macro::TokenStream;
use quote::quote;
use syn::{Data, DeriveInput, Fields, parse_macro_input};

#[proc_macro_derive(HelloMacro)]
pub fn hello_macro_derive(input: TokenStream) -> TokenStream {
    // 1. 입력 토큰을 구문 트리로 파싱
    let ast = parse_macro_input!(input as DeriveInput);
    let name = &ast.ident;

    // 2. 구조체 필드 이름 추출
    let field_names: Vec<String> = match &ast.data {
        Data::Struct(s) => match &s.fields {
            Fields::Named(named) => named
                .named
                .iter()
                .map(|f| f.ident.as_ref().unwrap().to_string())
                .collect(),
            _ => vec![],
        },
        _ => vec![],
    };

    // 3. quote! 로 생성할 코드 작성 (#변수 로 값 삽입, #(...)* 로 반복)
    let expanded = quote! {
        impl HelloMacro for #name {
            fn hello_macro() {
                println!("안녕하세요, 저는 {}입니다!", stringify!(#name));
            }
            fn fields() -> Vec<&'static str> {
                vec![ #( #field_names ),* ]
            }
        }
    };

    // 4. 토큰으로 반환
    TokenStream::from(expanded)
}
```

```rust
// (컴파일 검증: 별도 proc-macro 크레이트) app/src/main.rs
use hello_macro_derive::HelloMacro;

pub trait HelloMacro {
    fn hello_macro();
    fn fields() -> Vec<&'static str>;
}

#[derive(HelloMacro)]
struct Pancakes {
    flour: u32,
    sugar: u32,
}

fn main() {
    Pancakes::hello_macro();              // 안녕하세요, 저는 Pancakes입니다!
    println!("{:?}", Pancakes::fields()); // ["flour", "sugar"]
    let _ = Pancakes { flour: 1, sugar: 2 }.flour;
}
```

## 속성 매크로와 함수형 매크로

```rust
// (컴파일 검증 제외) - 시그니처 형태
use proc_macro::TokenStream;

// #[route(GET, "/users")] fn list_users() {}
#[proc_macro_attribute]
pub fn route(attr: TokenStream, item: TokenStream) -> TokenStream {
    // attr: GET, "/users"
    // item: fn list_users() {}
    item
}

// let q = sql!(SELECT * FROM users WHERE id = 1);
#[proc_macro]
pub fn sql(input: TokenStream) -> TokenStream {
    // 컴파일 타임에 SQL 문법 검사 후 코드 생성 가능
    input
}
```

## 실무에서 만나는 절차적 매크로

| 매크로 | 크레이트 | 하는 일 |
|---|---|---|
| `#[derive(Serialize, Deserialize)]` | serde | JSON 등 직렬화 코드 생성 |
| `#[derive(Parser)]` | clap | CLI 인자 파서 생성 |
| `#[derive(Error)]` | thiserror | Error/Display/From 구현 |
| `#[tokio::main]`, `#[tokio::test]` | tokio | 런타임 초기화 코드 삽입 |
| `sqlx::query!("...")` | sqlx | 컴파일 타임에 DB 스키마로 쿼리 검증 |
| `#[wasm_bindgen]` | wasm-bindgen | JS 바인딩 생성 |
| `#[derive(Component)]` | bevy | ECS 컴포넌트 등록 |

## serde derive 맛보기

```rust
// 외부 크레이트 serde (derive), serde_json 필요
use serde::{Deserialize, Serialize};

#[derive(Debug, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
struct UserProfile {
    user_id: u64,
    display_name: String,
    #[serde(default)]
    is_admin: bool,
    #[serde(skip_serializing_if = "Option::is_none")]
    bio: Option<String>,
}

fn main() -> Result<(), serde_json::Error> {
    let json = r#"{ "userId": 7, "displayName": "ferris" }"#;
    let user: UserProfile = serde_json::from_str(json)?;
    println!("{user:?}");

    let out = serde_json::to_string_pretty(&user)?;
    println!("{out}");
    Ok(())
}
```

## 매크로 사용 가이드

```
✅ 매크로가 적합한 경우
- 가변 인자 (println!, vec!)
- 반복적인 impl 블록 생성
- 트레이트 자동 구현 (derive)
- 컴파일 타임 검증 (sqlx::query!, include_str!)
- DSL (html!, sql!)

❌ 피해야 할 경우
- 함수나 제네릭으로 충분히 표현 가능한 경우
- 팀원이 읽고 유지보수하기 어려운 복잡한 매크로
- 에러 메시지가 알아보기 힘들어지는 경우
```

## 정리

- 매크로는 컴파일 타임에 코드를 생성하며, 토큰 단위로 동작해 C 매크로보다 안전하다
- `macro_rules!`는 패턴 매칭으로 코드를 전개, `$x:expr` 같은 프래그먼트와 `$(...),*` 반복 사용
- 매크로 내부 변수는 위생적이라 호출자 변수와 충돌하지 않는다
- 절차적 매크로(derive, attribute, function-like)는 별도 proc-macro 크레이트에서 `syn` + `quote`로 작성
- `cargo expand`로 전개 결과를 확인하자
- 함수로 가능하면 함수를 쓰자
