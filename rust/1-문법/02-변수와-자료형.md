# 변수와 자료형 - 불변이 기본인 언어

## 들어가며

Rust는 **정적 타입** 언어지만 타입 추론이 강력해서 타입을 일일이 적을 일이 많지 않습니다. 대신 JS/TS와 가장 크게 다른 점은 **변수가 기본적으로 불변**이라는 것입니다.

```
TypeScript          Rust
const x = 5;   →    let x = 5;
let x = 5;     →    let mut x = 5;
```

# 1. 변수

## let과 mut

```rust
fn main() {
    let x = 5;
    println!("x = {x}");

    // x = 6; // ❌ 컴파일 에러: cannot assign twice to immutable variable `x`

    let mut y = 5;
    y += 1;
    println!("y = {y}");
}
```

불변이 기본인 이유:
- 값이 바뀌지 않는다는 보장이 있으면 코드를 읽기 쉽고
- 컴파일러가 동시성 버그를 잡아내기 쉬워집니다

## 타입 명시

```rust
fn main() {
    let a: i32 = 10;
    let b = 10u8;        // 리터럴 접미사로 타입 지정
    let c = 1_000_000;   // _ 로 자릿수 구분 가능
    let d: f64 = 3.14;
    println!("{a} {b} {c} {d}");
}
```

## 섀도잉 (Shadowing)

같은 이름으로 `let`을 다시 선언하면 **새 변수**가 이전 변수를 가립니다.

```rust
fn main() {
    let spaces = "   ";          // &str
    let spaces = spaces.len();   // usize - 타입까지 바꿀 수 있음

    let x = 5;
    {
        let x = x * 2;           // 안쪽 스코프에서만 10
        println!("안쪽 x = {x}");
    }
    println!("바깥 x = {x}");    // 5
    println!("spaces = {spaces}");
}
```

`mut`과의 차이:
- `mut`은 **같은 변수의 값**을 바꿈 (타입 변경 불가)
- 섀도잉은 **새 변수**를 만듦 (타입 변경 가능, 결과는 다시 불변)

파싱 후 이름을 재사용하는 패턴에서 자주 씁니다. `let input = input.trim().parse::<u32>()?;`

## 상수와 static

```rust
const MAX_POINTS: u32 = 100_000;       // 컴파일 타임 상수, 타입 명시 필수, 인라인됨
static APP_NAME: &str = "my-app";      // 고정된 메모리 주소를 가진 전역 값

fn main() {
    println!("{APP_NAME}: {MAX_POINTS}");
}
```

```
const  → 사용하는 곳마다 값이 복사되어 들어감. 대부분의 경우 이것
static → 프로그램 전체에서 단 하나의 주소. 'static 수명
         static mut 은 unsafe (가급적 쓰지 말고 Atomic/Mutex/OnceLock 사용)
```

# 2. 스칼라 타입

## 정수

| 크기 | 부호 있음 | 부호 없음 |
|---|---|---|
| 8bit | `i8` | `u8` |
| 16bit | `i16` | `u16` |
| 32bit | `i32` (기본) | `u32` |
| 64bit | `i64` | `u64` |
| 128bit | `i128` | `u128` |
| 포인터 크기 | `isize` | `usize` |

- 타입을 안 적으면 정수는 `i32`로 추론됩니다.
- 배열 인덱스, 길이(`len()`)는 항상 `usize`입니다.

```rust
fn main() {
    let decimal = 98_222;
    let hex = 0xff;
    let octal = 0o77;
    let binary = 0b1111_0000;
    let byte = b'A';           // u8 전용 (65)
    println!("{decimal} {hex} {octal} {binary} {byte}");
}
```

## 정수 오버플로

디버그 빌드에서는 panic, 릴리스 빌드에서는 조용히 wrap됩니다. 의도를 명확히 하려면 메서드를 씁니다.

```rust
fn main() {
    let x: u8 = 250;

    println!("{:?}", x.checked_add(10));    // None      - 오버플로면 None
    println!("{}", x.wrapping_add(10));     // 4         - 순환
    println!("{}", x.saturating_add(10));   // 255       - 최댓값에서 멈춤
    println!("{:?}", x.overflowing_add(10)); // (4, true) - 결과 + 오버플로 여부
}
```

## 부동소수점, 불리언, 문자

```rust
fn main() {
    let f = 2.0;            // f64 (기본)
    let g: f32 = 3.0;

    let t = true;
    let is_big: bool = f > 1.0;

    let c = 'z';            // char - 4바이트 유니코드 스칼라 값
    let heart = '❤';
    let hangul = '한';

    println!("{f} {g} {t} {is_big} {c} {heart} {hangul}");
    println!("char 크기: {}바이트", std::mem::size_of::<char>()); // 4
}
```

- `char`는 작은따옴표, 문자열은 큰따옴표입니다.
- JS의 `number`처럼 하나로 통합된 숫자 타입은 없습니다.

## 타입 변환 (as, From, TryFrom)

Rust는 **암시적 형변환이 없습니다.** `i32 + i64`도 컴파일 에러입니다.

```rust
fn main() {
    let a: i32 = 10;
    let b: i64 = 20;

    // let c = a + b; // ❌ 컴파일 에러: mismatched types

    let c = a as i64 + b;           // as: 기본 타입 간 캐스팅 (잘림 발생 가능)
    let d = i64::from(a) + b;       // From: 손실 없는 변환만 제공
    let e: u8 = 300_i32 as u8;      // 44 - as는 조용히 잘라냄 (주의)
    let f = u8::try_from(300_i32);  // Err(...) - 실패 가능한 변환

    println!("{c} {d} {e} {f:?}");

    let parsed: i32 = "42".parse().unwrap();  // 문자열 → 숫자
    let s = 42.to_string();                   // 숫자 → 문자열
    println!("{parsed} {s}");
}
```

# 3. 복합 타입

## 튜플

서로 다른 타입을 고정 개수로 묶습니다.

```rust
fn main() {
    let tup: (i32, f64, char) = (500, 6.4, 'a');

    let (x, y, z) = tup;         // 구조 분해
    println!("{x} {y} {z}");

    println!("{}", tup.0);       // 인덱스 접근

    let unit = ();               // 빈 튜플 = unit 타입. 반환값 없는 함수의 반환 타입
    println!("{unit:?}");
}
```

## 배열

**길이가 고정**이고 스택에 올라갑니다. 길이까지 타입의 일부입니다 (`[i32; 3]`과 `[i32; 4]`는 다른 타입).

```rust
fn main() {
    let a = [1, 2, 3, 4, 5];
    let b: [i32; 5] = [1, 2, 3, 4, 5];
    let zeros = [0; 10];          // 0으로 채운 길이 10 배열

    println!("{} {} {}", a[0], b.len(), zeros.len());

    // 범위 밖 접근은 런타임 panic (C처럼 쓰레기 값을 읽지 않음)
    let idx = a.len();
    // println!("{}", a[idx]); // panic: index out of bounds

    // 안전하게 접근하려면 get
    println!("{:?}", a.get(idx)); // None
}
```

길이가 변하는 배열이 필요하면 `Vec<T>`를 씁니다. ([06-컬렉션과-문자열](./06-컬렉션과-문자열.md))

## 슬라이스 미리보기

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];
    let slice: &[i32] = &a[1..4];   // [20, 30, 40]
    println!("{slice:?}");
}
```

슬라이스는 "연속된 메모리의 일부를 빌려 보는 것"입니다. 참조와 함께 [기초개념/02-참조와-빌림](../2-기초개념/02-참조와-빌림.md)에서 자세히 다룹니다.

# 4. 출력 포맷팅

```rust
#[derive(Debug)]
struct Point {
    x: i32,
    y: i32,
}

fn main() {
    let name = "Rust";
    let version = 2024;
    let p = Point { x: 1, y: 2 };

    println!("{} {}", name, version);       // 위치 인자
    println!("{name} {version}");           // 변수 캡처 (Rust 1.58+)
    println!("{0} {1} {0}", "a", "b");      // 인덱스
    println!("{p:?}");                      // Debug 출력
    println!("{p:#?}");                     // 보기 좋게 여러 줄로
    println!("{:>8}|", "right");            // 오른쪽 정렬, 폭 8
    println!("{:<8}|", "left");             // 왼쪽 정렬
    println!("{:^8}|", "mid");              // 가운데 정렬
    println!("{:08.3}", 3.14159);           // 0패딩, 소수점 3자리 → 0003.142
    println!("{:#x} {:#b}", 255, 5);        // 0xff 0b101

    let s = format!("{name}-{version}");    // 문자열로 만들기
    eprintln!("stderr로 출력: {s}");
    dbg!(&p);                               // 파일:줄 번호와 함께 stderr 출력
}
```

- `{}`는 `Display` 트레이트, `{:?}`는 `Debug` 트레이트가 필요합니다.
- 직접 만든 타입은 `#[derive(Debug)]`만 붙이면 `{:?}` 출력이 됩니다.

// 한 줄 주석

```

문서 주석 안의 코드 블록은 `cargo test` 때 **실제로 실행되는 테스트(doctest)**가 됩니다.

## 정리

- `let`은 불변, 바꿀 거면 `let mut`
- 섀도잉으로 같은 이름에 새 값(다른 타입도 가능)을 묶을 수 있다
- 정수 기본 `i32`, 실수 기본 `f64`, 인덱스/길이는 `usize`
- 암시적 형변환 없음 → `as`, `From`, `TryFrom`, `parse` 사용
- 튜플은 이종 고정 묶음, 배열은 동종 고정 길이, 가변 길이는 `Vec`
- `{}`는 Display, `{:?}`는 Debug, `dbg!`로 빠르게 디버깅
