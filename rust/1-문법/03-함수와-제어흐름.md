# 함수와 제어 흐름 - 거의 모든 것이 표현식

## 들어가며

Rust 문법에서 가장 먼저 익숙해져야 할 개념은 **"문(statement)과 표현식(expression)의 구분"**입니다.

```
문(statement)   → 동작을 수행하고 값을 반환하지 않음. 세미콜론으로 끝남
표현식(expression) → 값으로 평가됨. if, match, loop, 블록 {} 모두 표현식
```

JS에서는 `if`가 문이라 삼항 연산자(`a ? b : c`)가 따로 있지만, Rust는 `if` 자체가 값을 반환하므로 삼항 연산자가 없습니다.

# 1. 함수

## 기본 형태

```rust
fn main() {
    greet("Rust");
    let sum = add(3, 4);
    println!("sum = {sum}");
}

fn greet(name: &str) {
    println!("Hello, {name}!");
}

// 매개변수 타입과 반환 타입은 반드시 명시 (추론하지 않음)
fn add(a: i32, b: i32) -> i32 {
    a + b // 세미콜론 없음 → 이 표현식의 값이 반환됨
}
```

- 함수 이름은 `snake_case`가 관례입니다.
- 함수는 호출 위치보다 뒤에 정의해도 됩니다 (호이스팅 고민 없음).
- **마지막 표현식이 반환값**입니다. 중간에 빠져나갈 때만 `return`을 씁니다.

## 세미콜론 하나의 차이

```rust
// ❌ 컴파일 에러 예제
fn plus_one(x: i32) -> i32 {
    x + 1;  // 세미콜론을 붙이면 문이 되어 () 를 반환
}

fn main() {
    println!("{}", plus_one(1));
}
```

```
error[E0308]: mismatched types
 --> src/main.rs:2:24
  |
2 | fn plus_one(x: i32) -> i32 {
  |    --------            ^^^ expected `i32`, found `()`
  |    |
  |    implicitly returns `()` as its body has no tail or `return` expression
3 |     x + 1;  // 세미콜론을 붙이면 문이 되어 () 를 반환
  |          - help: remove this semicolon to return this value
```

Rust 컴파일러는 에러 메시지에 **어떻게 고치면 되는지(help)**까지 알려주는 경우가 많습니다. 에러 메시지를 꼼꼼히 읽는 습관이 중요합니다.

## 블록도 표현식

```rust
fn main() {
    let y = {
        let x = 3;
        x * 2 // 블록의 값
    };
    println!("y = {y}"); // 6
}
```

## 조기 반환

```rust
fn divide(a: f64, b: f64) -> Option<f64> {
    if b == 0.0 {
        return None; // 조기 반환
    }
    Some(a / b)
}

fn main() {
    println!("{:?} {:?}", divide(10.0, 2.0), divide(1.0, 0.0));
}
```

## 반환하지 않는 함수: `!` (never 타입)

```rust
fn fail(msg: &str) -> ! {
    panic!("치명적 오류: {msg}");
}

fn main() {
    let n: i32 = if std::env::args().count() > 0 { 1 } else { fail("불가능") };
    println!("{n}");
}
```

`!`는 "절대 반환하지 않음"을 뜻합니다. `panic!`, `loop {}`, `std::process::exit()` 등이 해당하며 어떤 타입으로든 강제 변환될 수 있어서 `if`/`match`의 한 갈래로 쓸 수 있습니다.

# 2. if

## 기본

```rust
fn main() {
    let number = 7;

    if number < 5 {
        println!("5보다 작음");
    } else if number == 5 {
        println!("5");
    } else {
        println!("5보다 큼");
    }

    // 조건은 반드시 bool. JS처럼 truthy/falsy 없음
    // if number { } // ❌ 컴파일 에러: expected `bool`, found integer
}
```

## if는 표현식 (삼항 연산자 대체)

```rust
fn main() {
    let score = 85;
    let grade = if score >= 90 { "A" } else if score >= 80 { "B" } else { "C" };
    println!("{grade}");

    // 각 갈래의 타입이 같아야 함
    // let x = if true { 5 } else { "six" }; // ❌ 컴파일 에러: `if` and `else` have incompatible types
}
```

## let-else와 if let 체인 (미리보기)

```rust
fn parse_port(s: &str) -> u16 {
    // 패턴이 안 맞으면 else 블록 실행 (else 블록은 반드시 탈출해야 함)
    let Ok(port) = s.parse::<u16>() else {
        return 8080;
    };
    port
}

fn main() {
    println!("{}", parse_port("3000"));
    println!("{}", parse_port("abc"));

    let name: Option<&str> = Some("rust");
    // Rust 2024 에디션: if let 을 && 로 연결 (let chains, Rust 1.88+)
    if let Some(n) = name && n.len() > 3 {
        println!("긴 이름: {n}");
    }
}
```

패턴 매칭은 [05-패턴-매칭](./05-패턴-매칭.md)에서 자세히 다룹니다.

# 3. 반복문

## loop - 무한 반복

```rust
fn main() {
    let mut counter = 0;

    // loop 도 표현식. break 뒤에 값을 주면 그 값이 loop의 결과
    let result = loop {
        counter += 1;
        if counter == 10 {
            break counter * 2;
        }
    };

    println!("result = {result}"); // 20
}
```

## 루프 레이블

중첩 루프에서 바깥 루프를 빠져나갈 때 씁니다. 레이블은 `'` 로 시작합니다.

```rust
fn main() {
    let mut count = 0;
    'outer: loop {
        let mut remaining = 10;
        loop {
            if remaining == 9 {
                break; // 안쪽 loop 탈출
            }
            if count == 2 {
                break 'outer; // 바깥 loop 탈출
            }
            remaining -= 1;
        }
        count += 1;
    }
    println!("count = {count}");
}
```

## while

```rust
fn main() {
    let mut n = 3;
    while n != 0 {
        println!("{n}!");
        n -= 1;
    }
    println!("발사!");

    // while let: 패턴이 맞는 동안 반복
    let mut stack = vec![1, 2, 3];
    while let Some(top) = stack.pop() {
        println!("pop: {top}");
    }
}
```

## for

`for`는 **이터레이터**를 순회합니다. C 스타일 `for (i=0; i<n; i++)`는 없습니다.

```rust
fn main() {
    let arr = [10, 20, 30];

    for x in arr {
        println!("{x}");
    }

    // 범위(Range)
    for i in 0..3 {       // 0, 1, 2 (끝 미포함)
        print!("{i} ");
    }
    println!();

    for i in 1..=3 {      // 1, 2, 3 (끝 포함)
        print!("{i} ");
    }
    println!();

    for i in (1..=3).rev() {  // 3, 2, 1
        print!("{i} ");
    }
    println!();

    // 인덱스가 필요하면 enumerate
    for (i, x) in arr.iter().enumerate() {
        println!("arr[{i}] = {x}");
    }

    // step
    for i in (0..10).step_by(3) {  // 0, 3, 6, 9
        print!("{i} ");
    }
    println!();
}
```

인덱스로 순회하는 `for i in 0..arr.len() { arr[i] }` 보다 `for x in &arr`처럼 이터레이터를 쓰는 것이 관용적이고, 경계 검사도 줄어 더 빠를 수 있습니다.

# 4. 연산자

```rust
fn main() {
    // 산술
    println!("{}", 7 / 2);      // 3  (정수 나눗셈)
    println!("{}", 7 % 2);      // 1
    println!("{}", -7 / 2);     // -3 (0 방향으로 버림)
    println!("{}", (-7_i32).rem_euclid(2)); // 1 (수학적 나머지)
    println!("{}", 7.0 / 2.0);  // 3.5
    println!("{}", 2_i32.pow(10));    // 1024 (** 연산자 없음)
    println!("{}", 2.0_f64.powf(0.5));

    // 비교: == != < > <= >=   (=== 없음. 타입이 다르면 비교 자체가 컴파일 에러)
    // 논리: && || !
    // 비트: & | ^ ! << >>

    let mut x = 5;
    x += 1;  // 복합 대입 가능
    // x++;  // ❌ ++, -- 연산자 없음
    println!("{x}");
}
```

# 5. 클로저 미리보기

익명 함수는 **클로저**라고 부르며 `|인자| 본문` 형태입니다.

```rust
fn main() {
    let add = |a: i32, b: i32| a + b;
    let square = |x: i32| x * x;

    let factor = 3;
    let times = |x| x * factor; // 주변 변수 캡처

    println!("{} {} {}", add(1, 2), square(4), times(5));

    let nums = vec![1, 2, 3, 4];
    let doubled: Vec<i32> = nums.iter().map(|n| n * 2).collect();
    println!("{doubled:?}");
}
```

```
TypeScript: (a, b) => a + b
Rust:       |a, b| a + b
```

클로저의 캡처 방식(Fn/FnMut/FnOnce)은 [기초개념/06-클로저와-이터레이터](../2-기초개념/06-클로저와-이터레이터.md)에서 다룹니다.

# 6. 함수를 값으로 쓰기

```rust
fn double(x: i32) -> i32 {
    x * 2
}

// 함수 포인터 타입 fn(i32) -> i32
fn apply(f: fn(i32) -> i32, v: i32) -> i32 {
    f(v)
}

fn main() {
    println!("{}", apply(double, 5));        // 10
    println!("{}", apply(|x| x + 1, 5));     // 캡처 없는 클로저는 fn 포인터로 변환 가능

    let ops: [(&str, fn(i32) -> i32); 2] = [("double", double), ("negate", |x| -x)];
    for (name, op) in ops {
        println!("{name}: {}", op(7));
    }
}
```

## 정리

- 함수 시그니처의 매개변수/반환 타입은 반드시 명시
- 마지막 표현식이 반환값, 세미콜론을 붙이면 `()`가 된다
- `if`, `match`, `loop`, 블록 모두 값을 가지는 표현식 → 삼항 연산자 불필요
- 조건식은 반드시 `bool` (truthy/falsy 없음)
- 반복은 `loop`(값 반환 가능), `while`, `for x in 이터레이터`
- 범위는 `a..b`(끝 미포함), `a..=b`(끝 포함)
- `++`, `**`, `===`, 삼항 연산자는 없다
