# 컬렉션과 문자열 - Vec, String, HashMap

## 들어가며

배열과 튜플은 크기가 컴파일 타임에 고정되어 스택에 저장됩니다. 실행 중에 크기가 변하는 데이터는 **힙에 저장되는 컬렉션**을 씁니다.

```
JS/TS                 Rust
Array                 Vec<T>
string                String (소유) / &str (빌림)
Map / 객체             HashMap<K, V>, BTreeMap<K, V>
Set                   HashSet<T>, BTreeSet<T>
(없음)                 VecDeque<T>, BinaryHeap<T>
```

Rust를 처음 배울 때 가장 헷갈리는 것이 **`String`과 `&str`의 차이**입니다. 이 문서에서 확실히 짚고 넘어갑니다.

# 1. Vec<T>

## 생성과 추가

```rust
fn main() {
    let mut v: Vec<i32> = Vec::new();
    v.push(1);
    v.push(2);

    let v2 = vec![1, 2, 3];              // vec! 매크로
    let zeros = vec![0; 5];              // [0, 0, 0, 0, 0]
    let mut with_cap = Vec::with_capacity(100); // 미리 용량 확보 (재할당 줄이기)
    with_cap.push("a");

    println!("{v:?} {v2:?} {zeros:?} len={} cap>={}", with_cap.len(), with_cap.capacity());
}
```

## 읽기: 인덱스 vs get

```rust
fn main() {
    let v = vec![10, 20, 30];

    let third: &i32 = &v[2];          // 범위 밖이면 panic
    println!("{third}");

    match v.get(10) {                 // Option<&i32> 반환
        Some(x) => println!("{x}"),
        None => println!("10번 인덱스 없음"),
    }

    println!("{:?} {:?}", v.first(), v.last());
}
```

## 빌림 규칙과 Vec

```rust
// ❌ 컴파일 에러 예제
fn main() {
    let mut v = vec![1, 2, 3];
    let first = &v[0];   // 불변 참조
    v.push(4);           // 가변 참조 필요 → push 로 재할당되면 first가 댕글링 포인터가 될 수 있음
    println!("{first}");
}
```

```
error[E0502]: cannot borrow `v` as mutable because it is also borrowed as immutable
```

JS에서는 아무 문제 없는 코드지만, Rust는 "메모리 재할당으로 참조가 무효화되는 버그"를 컴파일 타임에 막습니다. (C++ 의 iterator invalidation 버그)

## 순회와 수정

```rust
fn main() {
    let mut v = vec![1, 2, 3];

    for x in &v {          // 불변 순회: x는 &i32
        print!("{x} ");
    }
    println!();

    for x in &mut v {      // 가변 순회: x는 &mut i32
        *x *= 10;          // 역참조해서 수정
    }
    println!("{v:?}");

    for x in v {           // 소유권을 가져가는 순회: 이후 v 사용 불가
        print!("{x} ");
    }
    println!();
}
```

## 자주 쓰는 메서드

```rust
fn main() {
    let mut v = vec![5, 3, 8, 1, 9, 3];

    v.sort();                         // [1, 3, 3, 5, 8, 9]
    v.dedup();                        // 연속 중복 제거 → [1, 3, 5, 8, 9]
    v.reverse();
    println!("{v:?}");

    println!("{}", v.contains(&8));
    v.retain(|&x| x > 2);             // 조건에 맞는 것만 남기기 (filter in-place)
    v.insert(0, 100);
    let removed = v.remove(1);        // 인덱스 삭제 (뒤 요소 당김, O(n))
    let popped = v.pop();             // Option<i32>
    v.extend([7, 7]);
    println!("{v:?} removed={removed} popped={popped:?}");

    let mut words = vec!["banana", "apple", "cherry"];
    words.sort_by(|a, b| b.cmp(a));   // 내림차순
    words.sort_by_key(|w| w.len());   // 길이 기준
    println!("{words:?}");

    let (evens, odds): (Vec<i32>, Vec<i32>) = (1..=6).partition(|n| n % 2 == 0);
    println!("{evens:?} {odds:?}");

    println!("{:?}", [1, 2, 3, 4, 5].chunks(2).collect::<Vec<_>>());   // [[1,2],[3,4],[5]]
    println!("{:?}", [1, 2, 3, 4].windows(2).collect::<Vec<_>>());     // [[1,2],[2,3],[3,4]]
    println!("{}", vec!["a", "b", "c"].join(", "));
}
```

## 여러 타입을 담고 싶을 때

Vec은 한 가지 타입만 담을 수 있으므로 enum으로 감쌉니다. (타입이 열려 있어야 하면 트레이트 객체 `Vec<Box<dyn Trait>>`)

```rust
#[derive(Debug)]
enum Cell {
    Int(i64),
    Float(f64),
    Text(String),
}

fn main() {
    let row = vec![Cell::Int(3), Cell::Text("blue".into()), Cell::Float(10.12)];
    println!("{row:?}");
}
```

# 2. 문자열: String과 &str

## 둘의 차이

```
String
- 힙에 할당된, 소유권을 가진, 늘어날 수 있는 UTF-8 문자열
- 내부적으로 Vec<u8> (포인터, 길이, 용량)

&str (문자열 슬라이스)
- 어딘가에 있는 UTF-8 바이트를 "빌려서 보는" 뷰
- (포인터, 길이) 두 개로 구성, 수정 불가
- 문자열 리터럴 "hello" 의 타입은 &'static str (바이너리에 박혀 있음)
```

```rust
fn main() {
    let literal: &str = "hello";               // 리터럴
    let owned: String = String::from("hello"); // 소유
    let owned2: String = "hello".to_string();
    let owned3: String = "hello".to_owned();
    let borrowed: &str = &owned;               // String → &str (자동 역참조)
    let slice: &str = &owned[1..4];            // "ell"

    println!("{literal} {owned} {owned2} {owned3} {borrowed} {slice}");
}
```

## 함수 매개변수는 &str로

```rust
// String 보다 &str 을 받으면 String, &String, 리터럴 모두 받을 수 있음
fn greet(name: &str) {
    println!("안녕, {name}");
}

fn main() {
    let s = String::from("러스트");
    greet(&s);       // &String → &str 자동 변환 (Deref coercion)
    greet("literal");
    greet(&s[..]);
}
```

**규칙**: 읽기만 하면 `&str`을 받고, 소유가 필요할 때(구조체에 저장 등)만 `String`을 받습니다.

## 문자열 수정과 연결

```rust
fn main() {
    let mut s = String::from("foo");
    s.push_str("bar");      // &str 추가
    s.push('!');            // char 추가
    println!("{s}");

    let s1 = String::from("Hello, ");
    let s2 = String::from("world");
    let s3 = s1 + &s2;      // s1은 이동되어 더 이상 사용 불가, s2는 빌림
    // println!("{s1}");    // ❌ borrow of moved value: `s1`
    println!("{s3} {s2}");

    // 여러 개를 이어 붙일 땐 format! 이 가독성이 좋음 (아무것도 이동하지 않음)
    let a = "tic";
    let b = "tac";
    let c = "toe";
    let joined = format!("{a}-{b}-{c}");
    println!("{joined}");
}
```

## 인덱싱이 안 되는 이유: UTF-8

```rust
fn main() {
    let hello = String::from("안녕하세요");

    // let h = hello[0]; // ❌ 컴파일 에러: the type `str` cannot be indexed by `{integer}`

    println!("바이트 길이: {}", hello.len());            // 15 (한글 1글자 = 3바이트)
    println!("글자 수: {}", hello.chars().count());      // 5

    // 문자 단위 순회
    for c in hello.chars() {
        print!("[{c}]");
    }
    println!();

    // n번째 글자
    println!("{:?}", hello.chars().nth(1));              // Some('녕')

    // 바이트 범위 슬라이스는 가능하지만 글자 경계가 아니면 panic
    println!("{}", &hello[0..3]);                         // "안"
    // println!("{}", &hello[0..2]);                      // panic: byte index 2 is not a char boundary

    // 안전하게 자르려면 get
    println!("{:?}", hello.get(0..2));                   // None
}
```

JS의 `"안녕".length`는 UTF-16 코드 유닛 수(2)지만 Rust의 `len()`은 **UTF-8 바이트 수**(6)입니다. 이모지 같은 복잡한 문자(grapheme cluster)를 다룰 땐 `unicode-segmentation` 크레이트를 씁니다.

## 자주 쓰는 문자열 메서드

```rust
fn main() {
    let s = "  Hello, Rust World  ";

    println!("[{}]", s.trim());
    println!("{}", s.to_uppercase());
    println!("{}", s.contains("Rust"));
    println!("{}", s.trim().starts_with("Hello"));
    println!("{}", s.replace("World", "세계"));
    println!("{:?}", s.find("Rust"));                 // Some(9) - 바이트 위치

    let csv = "a,b,,c";
    let parts: Vec<&str> = csv.split(',').collect();  // ["a", "b", "", "c"]
    println!("{parts:?}");

    let words: Vec<&str> = "one  two   three".split_whitespace().collect();
    println!("{words:?}");

    println!("{:?}", "key=value".split_once('='));    // Some(("key", "value"))

    for (i, line) in "첫째 줄\n둘째 줄".lines().enumerate() {
        println!("{i}: {line}");
    }

    let n: u32 = "42".parse().unwrap();
    let bad = "4x2".parse::<u32>();
    println!("{n} {bad:?}");

    let raw = r"C:\path\no\escape";                   // raw string
    let raw_quote = r#"{"json": "ok"}"#;              // 따옴표 포함
    println!("{raw} {raw_quote}");

    let bytes: &[u8] = b"bytes";                       // 바이트 문자열
    println!("{bytes:?}");
}
```

# 3. HashMap<K, V>

## 기본 사용

```rust
use std::collections::HashMap;

fn main() {
    let mut scores: HashMap<String, u32> = HashMap::new();
    scores.insert(String::from("Blue"), 10);
    scores.insert(String::from("Yellow"), 50);

    // 조회: Option<&V>
    let blue = scores.get("Blue").copied().unwrap_or(0);
    println!("Blue: {blue}");

    // 덮어쓰기
    scores.insert("Blue".to_string(), 25);

    // 순회 (순서는 보장되지 않음)
    for (team, score) in &scores {
        println!("{team}: {score}");
    }

    println!("{}", scores.contains_key("Red"));
    scores.remove("Yellow");

    // 튜플 이터레이터로부터 생성
    let map: HashMap<&str, i32> = [("a", 1), ("b", 2)].into_iter().collect();
    println!("{map:?}");
    let map2 = HashMap::from([("x", 10), ("y", 20)]);
    println!("{:?}", map2.get("x"));
}
```

## entry API - 없으면 넣고, 있으면 수정

```rust
use std::collections::HashMap;

fn main() {
    let text = "hello world wonderful world hello world";

    let mut counts: HashMap<&str, usize> = HashMap::new();
    for word in text.split_whitespace() {
        *counts.entry(word).or_insert(0) += 1;
    }
    println!("{counts:?}");

    // 그룹핑
    let mut by_len: HashMap<usize, Vec<&str>> = HashMap::new();
    for word in text.split_whitespace() {
        by_len.entry(word.len()).or_default().push(word);
    }
    println!("{by_len:?}");

    // 가장 많이 나온 단어
    let top = counts.iter().max_by_key(|&(_, c)| c);
    println!("{top:?}");
}
```

```
JS:   counts[word] = (counts[word] ?? 0) + 1;
Rust: *counts.entry(word).or_insert(0) += 1;
```

## 소유권 주의

```rust
use std::collections::HashMap;

fn main() {
    let key = String::from("color");
    let value = String::from("blue");

    let mut map = HashMap::new();
    map.insert(key, value); // key, value 소유권이 map으로 이동
    // println!("{key}");   // ❌ borrow of moved value: `key`
    println!("{map:?}");
}
```

# 4. 기타 컬렉션

```rust
use std::collections::{BTreeMap, BinaryHeap, HashSet, VecDeque};
use std::cmp::Reverse;

fn main() {
    // HashSet: 중복 없는 집합
    let a: HashSet<i32> = [1, 2, 3].into();
    let b: HashSet<i32> = [2, 3, 4].into();
    let mut inter: Vec<_> = a.intersection(&b).collect();
    inter.sort();
    println!("교집합 {inter:?}");

    // BTreeMap: 키 기준 정렬 유지 (순서 있는 출력이 필요할 때)
    let mut tree = BTreeMap::new();
    tree.insert("banana", 3);
    tree.insert("apple", 5);
    println!("{tree:?}"); // {"apple": 5, "banana": 3}

    // VecDeque: 양쪽 끝 삽입/삭제 O(1) (큐, BFS)
    let mut q = VecDeque::new();
    q.push_back(1);
    q.push_back(2);
    q.push_front(0);
    println!("{:?} {:?}", q.pop_front(), q);

    // BinaryHeap: 최대 힙 (우선순위 큐). 최소 힙은 Reverse 로 감싸기
    let mut heap = BinaryHeap::new();
    heap.push(3);
    heap.push(10);
    heap.push(1);
    println!("{:?}", heap.pop()); // Some(10)

    let mut min_heap = BinaryHeap::new();
    min_heap.push(Reverse(3));
    min_heap.push(Reverse(1));
    println!("{:?}", min_heap.pop()); // Some(Reverse(1))
}
```

| 필요 | 선택 |
|---|---|
| 순서 있는 목록, 뒤에 추가 | `Vec` |
| 앞뒤 추가/삭제 (큐) | `VecDeque` |
| 키-값, 순서 무관, 빠른 조회 | `HashMap` |
| 키-값, 키 정렬 유지 / 범위 조회 | `BTreeMap` |
| 중복 제거 | `HashSet` / `BTreeSet` |
| 우선순위 큐 | `BinaryHeap` |

## 정리

- 가변 길이 목록은 `Vec<T>`, 범위 밖 접근이 걱정되면 `get`
- 참조를 들고 있는 동안 컬렉션을 수정할 수 없다 (컴파일러가 댕글링 참조 방지)
- `String`은 소유하는 문자열, `&str`은 빌린 뷰. 매개변수는 `&str`로 받기
- 문자열은 UTF-8이라 정수 인덱싱 불가, `chars()`로 글자 단위 처리
- `HashMap`의 `entry().or_insert()` 패턴은 카운팅/그룹핑의 기본
- 정렬된 맵이 필요하면 `BTreeMap`, 큐는 `VecDeque`, 우선순위 큐는 `BinaryHeap`
