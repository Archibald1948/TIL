# 패턴 매칭 - match, if let, let-else

## 들어가며

패턴 매칭은 Rust 코드 어디에나 등장합니다. `match`는 JS의 `switch`와 비슷해 보이지만 훨씬 강력합니다.

```
switch (JS)                       match (Rust)
- 값 비교만 가능                   - 구조 분해, 범위, 조건(가드) 가능
- break 빠뜨리면 fall-through      - fall-through 없음
- default 없어도 됨                - 모든 경우를 처리하지 않으면 컴파일 에러
- 문(statement)                   - 표현식 (값을 반환)
```

패턴은 `match`뿐 아니라 `let`, 함수 매개변수, `for`, `if let`, `while let`에서도 쓰입니다.

# 1. match 기본

## 값 매칭

```rust
enum Coin {
    Penny,
    Nickel,
    Dime,
    Quarter,
}

fn value_in_cents(coin: Coin) -> u8 {
    match coin {
        Coin::Penny => {
            println!("행운의 페니!");
            1
        }
        Coin::Nickel => 5,
        Coin::Dime => 10,
        Coin::Quarter => 25,
    }
}

fn main() {
    println!("{}", value_in_cents(Coin::Penny));
    println!("{}", value_in_cents(Coin::Quarter));
    let _ = (Coin::Nickel, Coin::Dime);
}
```

## 모든 경우를 처리해야 함 (exhaustive)

```rust
// ❌ 컴파일 에러 예제
fn main() {
    let x: Option<i32> = Some(5);
    match x {
        Some(n) => println!("{n}"),
        // None 을 빠뜨림
    }
}
```


## 나머지 처리: `_` 와 변수 바인딩

```rust
fn main() {
    let dice = 9;

    match dice {
        3 => println!("모자 획득"),
        7 => println!("모자 잃음"),
        other => println!("{other}칸 이동"), // 값을 쓰려면 변수로 받기
    }

    match dice {
        3 => println!("모자 획득"),
        _ => (), // 값이 필요 없으면 _ , 아무것도 안 하려면 ()
    }
}
```

# 2. 다양한 패턴 문법

## 여러 값, 범위

```rust
fn classify(n: i32) -> &'static str {
    match n {
        0 => "영",
        1 | 2 | 3 => "작은 수",        // OR 패턴
        4..=9 => "한 자리",            // 범위 패턴 (끝 포함)
        10..100 => "두 자리",          // 끝 미포함 범위 (Rust 1.80+)
        i32::MIN..0 => "음수",
        _ => "큰 수",
    }
}

fn grade(c: char) -> &'static str {
    match c {
        'a'..='z' => "소문자",
        'A'..='Z' => "대문자",
        '가'..='힣' => "한글",
        _ => "기타",
    }
}

fn main() {
    for n in [0, 2, 7, 42, -5, 1000] {
        println!("{n}: {}", classify(n));
    }
    for c in ['r', 'R', '러', '!'] {
        println!("{c}: {}", grade(c));
    }
}
```

## 구조 분해 (destructuring)

```rust
struct Point {
    x: i32,
    y: i32,
}

enum Shape {
    Circle { center: Point, radius: f64 },
    Rect(Point, Point),
}

fn main() {
    // 구조체 분해
    let p = Point { x: 0, y: 7 };
    let Point { x, y: py } = p; // y 필드를 py라는 이름으로
    println!("{x} {py}");

    // match 안에서 필드 값 조건
    match p {
        Point { x: 0, y } => println!("y축 위, y = {y}"),
        Point { x, y: 0 } => println!("x축 위, x = {x}"),
        Point { x, y } => println!("({x}, {y})"),
    }

    // 중첩 분해
    let shapes = [
        Shape::Circle { center: Point { x: 1, y: 1 }, radius: 2.0 },
        Shape::Rect(Point { x: 0, y: 0 }, Point { x: 3, y: 4 }),
    ];
    for s in &shapes {
        match s {
            Shape::Circle { center: Point { x, y }, radius } => {
                println!("원 중심 ({x}, {y}), 반지름 {radius}")
            }
            Shape::Rect(Point { x: x1, y: y1 }, Point { x: x2, y: y2 }) => {
                println!("사각형 넓이 {}", (x2 - x1) * (y2 - y1))
            }
        }
    }

    // 튜플, 배열, 슬라이스
    let (a, _, c) = (1, 2, 3);
    println!("{a} {c}");

    let arr = [1, 2, 3, 4, 5];
    let [first, .., last] = arr;
    println!("{first} {last}");
}
```

## 슬라이스 패턴

```rust
fn describe(v: &[i32]) -> String {
    match v {
        [] => "비어 있음".to_string(),
        [one] => format!("하나: {one}"),
        [first, second] => format!("둘: {first}, {second}"),
        [first, .., last] => format!("{first} ... {last} (총 {}개)", v.len()),
    }
}

fn main() {
    println!("{}", describe(&[]));
    println!("{}", describe(&[1]));
    println!("{}", describe(&[1, 2]));
    println!("{}", describe(&[1, 2, 3, 4]));

    // 나머지를 슬라이스로 받기
    let args = ["run", "--release", "--verbose"];
    if let [cmd, rest @ ..] = args.as_slice() {
        println!("명령: {cmd}, 옵션: {rest:?}");
    }
}
```

## 매치 가드 (if 조건)

```rust
fn main() {
    let pair = (2, -2);

    match pair {
        (x, y) if x == y => println!("같음"),
        (x, y) if x + y == 0 => println!("합이 0"),
        (x, _) if x % 2 == 0 => println!("x가 짝수"),
        _ => println!("해당 없음"),
    }

    let num = Some(4);
    match num {
        Some(n) if n < 5 => println!("5 미만: {n}"),
        Some(n) => println!("{n}"),
        None => (),
    }
}
```

가드가 붙은 갈래는 exhaustive 검사에서 "모든 경우를 덮는다"고 간주되지 않으므로 보통 마지막에 가드 없는 갈래가 필요합니다.

## @ 바인딩

패턴을 검사하면서 동시에 값을 변수에 담습니다.

```rust
enum Msg {
    Hello { id: i32 },
}

fn main() {
    let msg = Msg::Hello { id: 5 };

    match msg {
        Msg::Hello { id: id_var @ 3..=7 } => println!("범위 안의 id: {id_var}"),
        Msg::Hello { id: 10..=12 } => println!("다른 범위 (값은 안 씀)"),
        Msg::Hello { id } => println!("그 외 id: {id}"),
    }

    let age = 25;
    match age {
        n @ 0..=12 => println!("어린이 {n}"),
        n @ 13..=19 => println!("청소년 {n}"),
        n => println!("성인 {n}"),
    }
}
```

## 참조와 ref

```rust
fn main() {
    let name = Some(String::from("rust"));

    // &name 을 매칭하면 안의 값도 참조로 바인딩됨 (default binding mode)
    match &name {
        Some(s) => println!("{s}"), // s: &String
        None => (),
    }
    println!("name 여전히 사용 가능: {name:?}");

    // match name { Some(s) => ... } 로 쓰면 String이 s로 이동해서 name을 못 쓰게 됨
}
```

예전 코드에서는 `Some(ref s)`처럼 `ref` 키워드를 볼 수 있는데, 지금은 대부분 `&값`을 매칭하는 방식으로 대체되었습니다.

# 3. if let / while let / let-else

## if let - 한 가지 경우만 관심 있을 때

```rust
fn main() {
    let config_max: Option<u8> = Some(3);

    // match 로 쓰면 장황함
    match config_max {
        Some(max) => println!("최대값 {max}"),
        _ => (),
    }

    // if let 으로 간결하게
    if let Some(max) = config_max {
        println!("최대값 {max}");
    } else {
        println!("설정 없음");
    }
}
```

## let chains (Rust 2024, 1.88+)

`if let`과 일반 조건을 `&&`로 연결할 수 있습니다. 중첩 `if let`을 평평하게 만들어 줍니다.

```rust
struct User {
    name: String,
    email: Option<String>,
}

fn main() {
    let user = Some(User { name: "kim".into(), email: Some("kim@x.com".into()) });

    // 예전 방식: 중첩
    if let Some(u) = &user {
        if let Some(email) = &u.email {
            if email.ends_with("@x.com") {
                println!("{} 사내 메일: {email}", u.name);
            }
        }
    }

    // let chains
    if let Some(u) = &user
        && let Some(email) = &u.email
        && email.ends_with("@x.com")
    {
        println!("{} 사내 메일: {email}", u.name);
    }
}
```

> let chains는 **edition 2024에서만** 사용할 수 있습니다.

## while let

```rust
fn main() {
    let mut tasks = vec!["a", "b", "c"];
    while let Some(task) = tasks.pop() {
        println!("처리: {task}");
    }
}
```

## let-else - 실패하면 빠져나가기

"값을 꺼내거나, 아니면 함수를 탈출" 패턴을 평평하게 씁니다. Rust 1.65+.

```rust
fn parse_kv(line: &str) -> Option<(String, i32)> {
    let Some((key, value)) = line.split_once('=') else {
        return None;
    };
    let Ok(num) = value.trim().parse::<i32>() else {
        return None;
    };
    Some((key.trim().to_string(), num))
}

fn main() {
    println!("{:?}", parse_kv("port = 8080"));
    println!("{:?}", parse_kv("invalid"));
    println!("{:?}", parse_kv("x = abc"));
}
```

`else` 블록은 반드시 `return`, `break`, `continue`, `panic!` 등으로 **흐름을 벗어나야** 합니다.

## matches! 매크로

bool만 필요할 때 씁니다.

```rust
#[derive(Debug)]
enum Status {
    Active,
    Inactive,
    Banned(u32),
}

fn main() {
    let list = [Status::Active, Status::Banned(3), Status::Inactive];
    let banned = list.iter().filter(|s| matches!(s, Status::Banned(days) if *days > 1)).count();
    println!("장기 정지: {banned}명");
    println!("{}", matches!('c', 'a'..='z'));
}
```

# 4. 패턴이 쓰이는 다른 곳들

```rust
fn print_coords(&(x, y): &(i32, i32)) {  // 함수 매개변수에서 분해
    println!("({x}, {y})");
}

fn main() {
    print_coords(&(3, 5));

    let pairs = vec![("a", 1), ("b", 2)];
    for (name, score) in &pairs {           // for 에서 분해
        println!("{name}: {score}");
    }

    let add = |(a, b): (i32, i32)| a + b;   // 클로저 매개변수
    println!("{}", add((1, 2)));
}
```

## 반박 가능성 (refutability)

```
반박 불가능(irrefutable) 패턴: 항상 매칭됨   → let x = 5; let (a, b) = pair;
반박 가능(refutable) 패턴: 실패할 수 있음     → Some(x), Ok(v), 1..=5

let, 함수 매개변수, for     → 반박 불가능 패턴만 가능
if let, while let, let-else → 반박 가능 패턴 사용
```

```rust
// ❌ 컴파일 에러 예제
fn main() {
    let opt: Option<i32> = None;
    let Some(x) = opt; // let 에는 반박 가능 패턴을 쓸 수 없음
    println!("{x}");
}
```

```
error[E0005]: refutable pattern in local binding
```

## 정리

- `match`는 모든 경우를 강제하는 표현식이며 fall-through가 없다
- `|`(OR), `a..=b`(범위), 구조 분해, `..`(나머지), `if`(가드), `@`(바인딩)를 조합할 수 있다
- 참조를 매칭하면 내부도 참조로 바인딩되어 소유권 이동을 피할 수 있다
- 한 경우만 관심 있으면 `if let`, 실패 시 탈출은 `let-else`
- 2024 에디션의 let chains로 중첩 `if let`을 평평하게
- bool 결과만 필요하면 `matches!`
