## Rust

Rust에 관한 TIL입니다.

Rust는 **메모리 안전성, 성능, 동시성**을 동시에 목표로 하는 시스템 프로그래밍 언어입니다. 가비지 컬렉터 없이 **소유권(ownership)** 규칙을 컴파일러가 검사해서 null 참조, 댕글링 포인터, 데이터 경쟁 같은 버그를 컴파일 단계에서 막아주고, 그러면서도 C/C++에 가까운 속도를 냅니다. CLI 도구, 웹 백엔드, WebAssembly, 임베디드, 게임, JS/Python 툴체인(swc, Biome, uv, Ruff) 등 다양한 분야에서 쓰이고 있습니다.

- 작성 기준: Rust 1.98 / edition 2024
- 문서 안의 예제 코드는 실제로 컴파일해서 확인했습니다.

### 학습 로드맵

```
1. 문법          설치 → 변수/타입 → 함수/제어흐름 → 구조체/열거형 → 패턴 매칭 → 컬렉션 → 모듈
2. 기초 개념      소유권 → 참조/빌림 → 에러 처리 → 제네릭 → 트레이트 → 클로저/이터레이터 → 테스트
3. 심화 개념      라이프타임 → 스마트 포인터 → 동시성 → async/await → 매크로 → unsafe/FFI → 고급 트레이트
4. 프로젝트       minigrep → CLI 도구 → axum API 서버 → 관심 분야 (WASM, Tauri, Bevy, 임베디드...)
```

Rust에서 가장 큰 벽은 **소유권과 빌림**입니다. `2-기초개념`의 01, 02 문서는 이해될 때까지 반복해서 보는 것을 추천합니다.
