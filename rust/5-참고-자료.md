# Rust 참고 자료 모음

## 들어가며

Rust 학습에 필요한 공식 사이트, 문서, GitHub 저장소, 한국어 자료, 커뮤니티 링크를 한곳에 모았습니다.

- 모든 링크는 2026년 9월 기준으로 접속 확인했습니다.
- 한국어 번역본은 원문보다 버전이 뒤처지는 경우가 많아 **기준 버전이나 마지막 업데이트 시점**을 함께 적었습니다.
- 추천 순서: 한국어 러스트 북 → Rustlings → Comprehensive Rust → Rust by Example → 관심 분야 문서

## 정리

- 입문은 **한국어 러스트 북(doc.rust-kr.org)** + **Rustlings** + **Comprehensive Rust 한국어**
- 막히면 에러 코드 색인, Rust Users Forum, 한국 러스트 사용자 그룹 Discord
- 크레이트는 crates.io에서 찾고 docs.rs에서 문서 확인, 무엇을 쓸지 모르겠으면 blessed.rs
- 한국어 번역본은 버전이 뒤처질 수 있으니 최신 기능(async, 2024 에디션)은 영문 원문 확인
