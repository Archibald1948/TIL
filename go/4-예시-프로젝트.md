# Go로 만들면 좋은 예시 프로젝트

## 들어가며

문법을 다 배웠다면 이제 직접 만들어볼 차례입니다. 그런데 "무엇을 만들어야 Go를 제대로 연습할 수 있을까?"가 고민입니다.

Go가 특히 강한 분야는 명확합니다.

```
✅ 네트워크 서버 (HTTP API, gRPC, WebSocket, 프록시)
   → 고루틴 기반 동시성, 강력한 net/http 표준 라이브러리

✅ CLI / 개발자 도구
   → 런타임 없는 단일 바이너리, 쉬운 크로스 컴파일, 빠른 시작 속도

✅ 클라우드 인프라 / DevOps 도구
   → Docker, Kubernetes, Terraform, Prometheus 가 전부 Go

✅ 동시성이 핵심인 작업 (크롤러, 파이프라인, 워커)
   → 고루틴 + 채널 + context
```

반대로 이런 분야는 다른 언어가 더 어울리는 경우가 많습니다.

```
△ 프론트엔드 UI  → TypeScript
△ 데이터 분석/ML → Python
△ 초저지연·GC 불가 시스템 (게임 엔진 코어, 커널, 임베디드) → Rust, C++
```

이 문서는 난이도별로 프로젝트를 정리하고, 각 프로젝트마다 **왜 Go가 적합한지, 추천 라이브러리, 참고할 실제 오픈소스**를 함께 적었습니다.

```go
// cobra 로 만든 CLI 뼈대
package main

import (
	"fmt"
	"os"

	"github.com/spf13/cobra"
)

func main() {
	var upper bool

	rootCmd := &cobra.Command{
		Use:   "greet",
		Short: "인사말을 출력하는 CLI",
	}

	helloCmd := &cobra.Command{
		Use:   "hello [name]",
		Short: "이름에게 인사",
		Args:  cobra.ExactArgs(1),
		Run: func(cmd *cobra.Command, args []string) {
			msg := "안녕, " + args[0] + "!"
			if upper {
				msg = "HELLO, " + args[0] + "!"
			}
			fmt.Println(msg)
		},
	}
	helloCmd.Flags().BoolVarP(&upper, "upper", "u", false, "영어 대문자로 출력")

	rootCmd.AddCommand(helloCmd)
	if err := rootCmd.Execute(); err != nil {
		os.Exit(1)
	}
}
```

```bash
go run . --help            # 도움말, completion 명령 자동 생성
```

## 2-1. TUI 앱 (터미널 대시보드, Git 클라이언트, 파일 탐색기)

```
아이디어: 시스템 모니터(CPU/메모리), 쿠버네티스 파드 뷰어, 할 일 관리 TUI, 포모도로 타이머
```

```
왜 Go?
- Charm 생태계(bubbletea, lipgloss, bubbles)가 매우 성숙함
- 단일 바이너리라 배포가 쉬움
- The Elm Architecture(Model-Update-View) 로 상태 관리가 깔끔

배우는 것:
- 이벤트 루프, 메시지 기반 상태 업데이트
- 고루틴에서 받아온 데이터를 UI 로 전달 (tea.Cmd)
```

```go
// bubbletea v2 로 만든 체크리스트 TUI
package main

import (
	"fmt"
	"os"

	tea "charm.land/bubbletea/v2"
)

// Model: 앱의 상태
type model struct {
	cursor  int
	choices []string
	picked  map[int]bool
}

func (m model) Init() tea.Cmd { return nil }

// Update: 메시지(키 입력 등)를 받아 새 상태를 반환
func (m model) Update(msg tea.Msg) (tea.Model, tea.Cmd) {
	if key, ok := msg.(tea.KeyPressMsg); ok {
		switch key.String() {
		case "q", "ctrl+c":
			return m, tea.Quit
		case "up", "k":
			if m.cursor > 0 {
				m.cursor--
			}
		case "down", "j":
			if m.cursor < len(m.choices)-1 {
				m.cursor++
			}
		case "space", "enter":
			m.picked[m.cursor] = !m.picked[m.cursor]
		}
	}
	return m, nil
}

// View: 상태를 화면으로 렌더링
func (m model) View() tea.View {
	s := "오늘 공부할 언어는?\n\n"
	for i, c := range m.choices {
		cursor := " "
		if m.cursor == i {
			cursor = ">"
		}
		check := " "
		if m.picked[i] {
			check = "x"
		}
		s += fmt.Sprintf("%s [%s] %s\n", cursor, check, c)
	}
	return tea.NewView(s + "\n↑/↓ 이동, space 선택, q 종료\n")
}

func main() {
	m := model{choices: []string{"Go", "Rust", "Zig"}, picked: map[int]bool{}}
	if _, err := tea.NewProgram(m).Run(); err != nil {
		fmt.Println(err)
		os.Exit(1)
	}
}
```

> bubbletea는 2026년 기준 v2가 최신이며 import 경로가 `charm.land/bubbletea/v2`로 바뀌었습니다. 인터넷의 많은 예제는 v1(`github.com/charmbracelet/bubbletea`, `View() string`, `tea.KeyMsg`) 기준이니 버전을 확인하세요.

```go
package main

import (
	"fmt"
	"log"

	"github.com/gocolly/colly/v2"
)

func main() {
	c := colly.NewCollector(
		colly.AllowedDomains("go.dev"),
		colly.MaxDepth(2),
		colly.Async(true), // 내부적으로 고루틴 사용
	)
	// 동시 요청 수 제한 (대상 사이트에 부담 주지 않기)
	c.Limit(&colly.LimitRule{DomainGlob: "*", Parallelism: 2})

	c.OnHTML("title", func(e *colly.HTMLElement) {
		fmt.Printf("%s → %s\n", e.Request.URL, e.Text)
	})
	c.OnHTML("a[href]", func(e *colly.HTMLElement) {
		e.Request.Visit(e.Attr("href")) // 링크 따라가기
	})
	c.OnError(func(r *colly.Response, err error) {
		log.Println(r.Request.URL, err)
	})

	c.Visit("https://go.dev/")
	c.Wait()
}
```

## 2-3. 실시간 채팅 서버 (WebSocket)

```
기능: 채팅방 입장/퇴장, 브로드캐스트, 접속자 목록, 귓속말, 메시지 히스토리
```

```
왜 Go?
- 연결 하나당 고루틴 하나 → 수만 동시 접속도 단순한 코드로 처리
- 채널로 브로드캐스트 허브를 자연스럽게 표현

배우는 것:
- 연결 관리 (Hub 패턴), 느린 클라이언트 처리 (클라이언트별 버퍼 채널)
- 핑/퐁 heartbeat, 재접속
- 서버 여러 대로 확장 → Redis Pub/Sub 또는 NATS
```

```go
package main

import (
	"context"
	"log/slog"
	"net/http"
	"sync"

	"github.com/coder/websocket"
)

// Hub: 접속한 모든 클라이언트를 관리하고 메시지를 브로드캐스트
type Hub struct {
	mu      sync.Mutex
	clients map[*websocket.Conn]struct{}
}

func NewHub() *Hub {
	return &Hub{clients: make(map[*websocket.Conn]struct{})}
}

func (h *Hub) add(c *websocket.Conn) {
	h.mu.Lock()
	defer h.mu.Unlock()
	h.clients[c] = struct{}{}
}

func (h *Hub) remove(c *websocket.Conn) {
	h.mu.Lock()
	defer h.mu.Unlock()
	delete(h.clients, c)
}

func (h *Hub) broadcast(ctx context.Context, msg []byte) {
	h.mu.Lock()
	defer h.mu.Unlock()
	for c := range h.clients {
		// 느린 클라이언트 하나가 전체를 막지 않도록 실무에서는 클라이언트별 송신 채널을 둠
		if err := c.Write(ctx, websocket.MessageText, msg); err != nil {
			slog.Warn("전송 실패", "err", err)
		}
	}
}

func (h *Hub) ServeHTTP(w http.ResponseWriter, r *http.Request) {
	c, err := websocket.Accept(w, r, nil)
	if err != nil {
		return
	}
	defer c.CloseNow()

	h.add(c)
	defer h.remove(c)

	ctx := r.Context()
	for {
		_, msg, err := c.Read(ctx) // 클라이언트 메시지 대기
		if err != nil {
			return // 연결 종료
		}
		h.broadcast(ctx, msg)
	}
}

func main() {
	mux := http.NewServeMux()
	mux.Handle("/ws", NewHub())
	slog.Info("ws://localhost:8080/ws")
	http.ListenAndServe(":8080", mux)
}
```

## 2-4. 리버스 프록시 / 로드 밸런서

```
기능: 라운드 로빈/최소 연결 분산, 헬스체크로 죽은 백엔드 제외, 요청 로깅, rate limit
```

```
왜 Go?
- 표준 라이브러리 net/http/httputil.ReverseProxy 가 이미 강력함
- Caddy, Traefik 같은 프로덕션 프록시가 Go 로 만들어짐

배우는 것:
- HTTP 프록시 동작 (헤더, X-Forwarded-For, 스트리밍)
- atomic 카운터, 백그라운드 헬스체크 고루틴 (Ticker)
- TLS 종료, graceful shutdown
```

```go
package main

import (
	"log"
	"net/http"
	"net/http/httputil"
	"net/url"
	"sync/atomic"
)

// 라운드 로빈 리버스 프록시
func newLoadBalancer(targets []string) http.Handler {
	backends := make([]*url.URL, len(targets))
	for i, t := range targets {
		u, err := url.Parse(t)
		if err != nil {
			log.Fatal(err)
		}
		backends[i] = u
	}

	var next atomic.Uint64
	return &httputil.ReverseProxy{
		Rewrite: func(r *httputil.ProxyRequest) {
			target := backends[next.Add(1)%uint64(len(backends))]
			r.SetURL(target)  // 요청을 선택된 백엔드로
			r.SetXForwarded() // X-Forwarded-For 등 헤더 설정
		},
	}
}

func main() {
	lb := newLoadBalancer([]string{
		"http://localhost:9001",
		"http://localhost:9002",
	})
	log.Println("로드밸런서: http://localhost:8080")
	log.Fatal(http.ListenAndServe(":8080", lb))
}
```

> Go 1.26부터 `ReverseProxy.Director`는 deprecated이고 `Rewrite`를 권장합니다.

## 추천 학습 순서

```

```

## 모든 프로젝트에 공통으로 넣어보면 좋은 것

```
✅ go test ./... + 테이블 주도 테스트 + httptest
✅ go test -race 를 CI 에서 실행
✅ golangci-lint
✅ log/slog 구조화 로깅
✅ context 로 타임아웃/취소 전파
✅ graceful shutdown
✅ 멀티 스테이지 Dockerfile (최종 이미지는 distroless 또는 scratch)
✅ GoReleaser 로 여러 OS 바이너리 자동 릴리스
✅ README 에 설치 방법: go install github.com/you/project@latest
```

## 배포용 Dockerfile 예시

```dockerfile
# 1단계: 빌드
FROM golang:1.27 AS build
WORKDIR /src
COPY go.mod go.sum ./
RUN go mod download
COPY . .
RUN CGO_ENABLED=0 go build -trimpath -ldflags="-s -w" -o /app ./cmd/server

# 2단계: 실행 (바이너리만 복사 → 수 MB ~ 수십 MB 이미지)
FROM gcr.io/distroless/static-debian13
COPY --from=build /app /app
USER nonroot:nonroot
ENTRYPOINT ["/app"]
```

## 정리

- Go는 네트워크 서버, CLI, 클라우드/DevOps 도구, 동시성 작업에 특히 강함
- 입문: todo CLI, 표준 라이브러리 REST API, URL 단축기, 정적 사이트 생성기
- 중급: TUI(bubbletea), 크롤러(colly), WebSocket 채팅, 리버스 프록시, 모니터링 봇
- 고급: gRPC 마이크로서비스, Redis 클론, Raft 분산 KV, 컨테이너 런타임, 쿠버네티스 오퍼레이터
- Docker, Kubernetes, Hugo, Caddy, lazygit, fzf 등 유명 오픈소스 코드를 읽으며 실전 패턴 학습
