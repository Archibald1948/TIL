# Go 참고 자료 모음

## 들어가며

Go 학습에 도움이 되는 공식 문서, GitHub 저장소, 한국어 자료, 커뮤니티, 연습 사이트를 한곳에 모았습니다.

```
표기:
[한국어]  → 한국어로 된 자료
(구버전)  → 번역/작성 시점이 오래되어 최신 문법(제네릭, 이터레이터 등)이 빠져 있을 수 있음
```

> 모든 링크는 2026년 9월 기준으로 접속 가능 여부를 확인했습니다. 번역 자료는 원문보다 늦게 갱신되므로, 최신 내용은 항상 공식 문서와 릴리스 노트로 확인하세요.
