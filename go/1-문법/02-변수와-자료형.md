# 변수와 자료형 - 정적 타입인데 타입을 거의 안 쓰는 언어

## 들어가며

Go는 정적 타입 언어지만, 타입 추론 덕분에 코드가 동적 언어처럼 짧습니다.

```
JavaScript:  let count = 10
TypeScript:  let count: number = 10
Go:          count := 10          // int로 추론
```

그리고 JS/TS와 가장 크게 다른 점이 있습니다.

```
✅ 모든 변수는 선언과 동시에 "제로값"으로 초기화된다 (undefined 없음)
✅ 암묵적 형변환이 없다 (int + float64 는 컴파일 에러)
✅ 사용하지 않는 지역 변수는 컴파일 에러
```

# 1. 변수 선언

## var 키워드

```go
package main

import "fmt"

func main() {
	var name string = "gopher" // 타입 + 값
	var age = 10               // 타입 추론
	var score float64          // 값 생략 → 제로값 0

	// 여러 개 한 번에
	var (
		host = "localhost"
		port = 8080
	)

	fmt.Println(name, age, score, host, port)
	// 출력: gopher 10 0 localhost 8080
}
```

## 짧은 선언 :=

함수 안에서만 쓸 수 있고, 실무에서 가장 많이 씁니다.

```go
package main

import "fmt"

func main() {
	name := "gopher"
	x, y := 1, 2

	// 왼쪽에 새 변수가 하나라도 있으면 := 재사용 가능
	x, z := 10, 3

	fmt.Println(name, x, y, z)
	// 출력: gopher 10 2 3
}
```

```
var  → 패키지 레벨 변수, 제로값으로 선언만 할 때, 타입을 명시하고 싶을 때
:=   → 함수 안에서 값과 함께 선언할 때 (대부분의 경우)
```

## 사용하지 않는 변수

```go
package main

func main() {
	x := 10 // 컴파일 에러
}
```

```
declared and not used: x
```

값이 필요 없으면 빈 식별자 `_`로 버립니다.

```go
_, err := fmt.Println("hi") // 첫 번째 반환값은 버림
```

# 2. 제로값 (Zero Value)

선언만 하고 값을 넣지 않으면 타입별 기본값이 들어갑니다.

```go
package main

import "fmt"

func main() {
	var i int
	var f float64
	var b bool
	var s string
	var p *int
	var sl []int
	var m map[string]int
	var err error

	fmt.Printf("%v %v %v %q %v %v %v %v\n", i, f, b, s, p, sl, m, err)
	// 출력: 0 0 false "" <nil> [] map[] <nil>

	fmt.Println(sl == nil, m == nil)
	// 출력: true true
}
```

| 타입 | 제로값 |
|------|--------|
| 숫자 (int, float64 ...) | `0` |
| bool | `false` |
| string | `""` |
| 포인터, 슬라이스, 맵, 채널, 함수, 인터페이스 | `nil` |
| 구조체 | 모든 필드가 각자의 제로값 |

> Go에서는 "제로값이 바로 쓸모 있게" 설계하는 것이 관례입니다. 예: `var mu sync.Mutex`는 초기화 없이 바로 사용 가능, `var buf bytes.Buffer`도 바로 쓸 수 있음.

# 3. 기본 자료형

## 정수

```
int     int8   int16   int32   int64     → 부호 있음
uint    uint8  uint16  uint32  uint64    → 부호 없음
uintptr                                  → 포인터 크기의 정수

int / uint 는 64비트 시스템에서 64비트
byte  = uint8 의 별칭
rune  = int32 의 별칭 (유니코드 코드 포인트 하나)
```

특별한 이유가 없으면 **정수는 `int`** 를 씁니다.

## 실수와 복소수

```go
package main

import "fmt"

func main() {
	var f32 float32 = 0.1
	a, b := 0.1, 0.2 // 기본은 float64

	fmt.Println(f32, a+b)
	// 출력: 0.1 0.30000000000000004

	// 참고: 상수끼리 계산하면 컴파일 타임에 정밀 계산되어 0.3이 나온다
	fmt.Println(0.1 + 0.2)
	// 출력: 0.3

	c := complex(1, 2) // complex128
	fmt.Println(c, real(c), imag(c))
	// 출력: (1+2i) 1 2
}
```

## bool

```go
ok := true
// Go에는 truthy/falsy가 없다
// if 1 { }       → 컴파일 에러
// if "" { }      → 컴파일 에러
```

## 문자열

```go
package main

import "fmt"

func main() {
	s := "Hello, 고퍼"

	// 문자열은 불변(immutable) 바이트 시퀀스 (UTF-8)
	fmt.Println(len(s)) // 바이트 길이
	// 출력: 13

	fmt.Println(s[0]) // 인덱싱하면 byte
	// 출력: 72

	// 문자 단위(rune)로 순회하려면 range
	for i, r := range "고퍼" {
		fmt.Println(i, string(r))
	}
	// 출력:
	// 0 고
	// 3 퍼

	// 글자 수는 rune 슬라이스로 변환해서
	fmt.Println(len([]rune(s)))
	// 출력: 9

	// 원시 문자열 리터럴 (백틱): 이스케이프 처리 안 함, 여러 줄 가능
	raw := `C:\path\to
두 번째 줄`
	fmt.Println(raw)
}
```

```
"..."  → 해석된 문자열 (\n, \t 이스케이프 동작)
`...`  → 원시 문자열 (정규식, JSON, SQL 쓸 때 편함)
'가'   → rune 리터럴 (문자열 아님!)
```

한글 한 글자는 UTF-8에서 3바이트라서 `len("고퍼")`는 6입니다. JS의 `"고퍼".length === 2`와 다르니 주의.

# 4. 타입 변환

Go에는 **암묵적 형변환이 없습니다.** 모든 변환은 `타입(값)` 형태로 명시합니다.

```go
i := 42
f := float64(i)  // int → float64
n := int(3.9)    // 컴파일 에러: cannot convert 3.9 (untyped float constant) to type int
```

상수 변환은 컴파일 타임에 표현 가능한지, 범위를 벗어나지 않는지 검사합니다.

```go
package main

import "fmt"

func main() {
	u := uint8(300) // 컴파일 에러
	fmt.Println(u)
}
```

```
constant 300 overflows uint8
```

변수를 통한 변환은 런타임에 잘립니다.

```go
package main

import (
	"fmt"
	"strconv"
)

func main() {
	big := 300
	fmt.Println(uint8(big))
	// 출력: 44

	// 서로 다른 숫자 타입끼리 연산하려면 변환 필수
	a := 10
	b := 2.5
	fmt.Println(float64(a) * b)
	// 출력: 25

	// 숫자 ↔ 문자열은 strconv
	n, err := strconv.Atoi("123")
	fmt.Println(n, err)
	// 출력: 123 <nil>

	s := strconv.Itoa(456)
	fmt.Println(s + "!")
	// 출력: 456!

	// 주의: string(숫자)는 "숫자"가 아니라 해당 코드 포인트의 문자
	fmt.Println(string(rune(65)))
	// 출력: A

	// 문자열 ↔ 바이트/룬 슬라이스
	bs := []byte("go")
	rs := []rune("고퍼")
	fmt.Println(bs, rs, string(bs), string(rs))
	// 출력: [103 111] [44256 54140] go 고퍼
}
```

# 5. 상수와 iota

## const

```go
const Pi = 3.14159
const (
	StatusOK       = 200
	StatusNotFound = 404
)
```

타입을 지정하지 않은 상수는 **untyped constant**라서 쓰이는 곳에 맞춰 유연하게 변환됩니다.

```go
package main

import "fmt"

const Big = 1 << 100 // int 범위를 넘지만 상수라서 OK

func main() {
	var f float64 = Big >> 98 // 사용할 때 범위 안이면 문제없음
	fmt.Println(f)
	// 출력: 4
}
```

## iota (열거형 대용)

Go에는 `enum` 키워드가 없고 `iota`로 연속된 상수를 만듭니다.

```go
package main

import "fmt"

type Weekday int

const (
	Sunday  Weekday = iota // 0
	Monday                 // 1
	Tuesday                // 2
)

type Size int64

const (
	_  Size = iota             // 0은 버림
	KB Size = 1 << (10 * iota) // 1 << 10
	MB                         // 1 << 20
	GB                         // 1 << 30
)

// String 메서드를 달면 fmt로 출력할 때 이름이 나온다
func (d Weekday) String() string {
	return [...]string{"일", "월", "화"}[d]
}

func main() {
	fmt.Println(Sunday, Monday, Tuesday)
	// 출력: 일 월 화

	fmt.Println(KB, MB, GB)
	// 출력: 1024 1048576 1073741824
}
```

> 상수가 많으면 `go tool stringer -type=Weekday`로 `String()` 메서드를 자동 생성할 수 있습니다.

# 6. 타입 정의와 별칭

```go
package main

import "fmt"

type UserID int64      // 새로운 타입 정의 (int64와 다른 타입)
type Celsius = float64 // 별칭 (완전히 같은 타입)

func main() {
	var id UserID = 10
	var n int64 = 20

	// fmt.Println(id + n) // 컴파일 에러: 타입이 다름
	fmt.Println(id + UserID(n))
	// 출력: 30

	var c Celsius = 36.5
	var f float64 = c // 별칭이라 그대로 대입 가능
	fmt.Println(f)
	// 출력: 36.5
}
```

```
type A B    → 새 타입. 메서드를 붙일 수 있고, 실수로 섞어 쓰는 걸 막아줌
type A = B  → 이름만 다른 같은 타입. 주로 리팩터링/호환성 용도
```

# 7. 출력 포맷 (fmt 동사)

```go
package main

import "fmt"

type Point struct {
	X, Y int
}

func main() {
	p := Point{1, 2}

	fmt.Printf("%v\n", p)  // {1 2}         기본 형식
	fmt.Printf("%+v\n", p) // {X:1 Y:2}     필드 이름 포함
	fmt.Printf("%#v\n", p) // main.Point{X:1, Y:2}  Go 문법 형태
	fmt.Printf("%T\n", p)  // main.Point    타입

	fmt.Printf("%d %b %x %o\n", 42, 42, 42, 42) // 42 101010 2a 52
	fmt.Printf("%.2f %e\n", 3.14159, 1234.5)    // 3.14 1.234500e+03
	fmt.Printf("%s %q\n", "go", "go")           // go "go"
	fmt.Printf("%5d|%-5d|\n", 7, 7)             //     7|7    |
	fmt.Printf("%t %p\n", true, &p)             // true 0xc000... (주소)

	s := fmt.Sprintf("%s:%d", "localhost", 8080) // 문자열로 반환
	fmt.Println(s)
}
```

실무에서 디버깅할 때는 `%+v`를 가장 많이 씁니다.

# 8. 변수 스코프와 섀도잉

```go
package main

import "fmt"

var global = "패키지 레벨"

func main() {
	x := 1
	if true {
		x := 2 // 새로운 x (바깥 x를 가림 = 섀도잉)
		fmt.Println(x)
	}
	fmt.Println(x)
	// 출력:
	// 2
	// 1
	fmt.Println(global)
}
```

섀도잉은 특히 `err`에서 버그를 만들기 쉽습니다.

```go
var err error
if cond {
	result, err := doSomething() // 여기서 err는 새 변수!
	_ = result
}
// 바깥 err는 여전히 nil
```

`golangci-lint`에서 `govet`의 `shadow` 검사를 켜면 이런 실수를 잡을 수 있습니다.

## 정리

- `var`는 제로값 선언/패키지 레벨, `:=`는 함수 안에서 값과 함께 선언
- 모든 변수는 제로값으로 초기화되며 `undefined`가 없음
- 암묵적 형변환 없음, 숫자 ↔ 문자열은 `strconv`
- 문자열은 UTF-8 바이트 시퀀스, 글자 단위는 `rune`과 `range`로
- `enum` 대신 `const` + `iota`, 출력용 이름은 `String()` 메서드
- `type A B`는 새 타입, `type A = B`는 별칭
- 디버깅 출력은 `fmt.Printf("%+v")`
