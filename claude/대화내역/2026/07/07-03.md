## 1. Remote Control이란?

Remote Control은 로컬 터미널의 Claude Code 세션을 `claude.ai/code`나 Claude 모바일 앱(iOS/Android)과 연결해주는 동기화 계층입니다. 클라우드로 코드를 옮기는 방식이 아니라, 세션은 계속 로컬 머신에서 실행되고 웹/모바일 인터페이스는 그 로컬 세션을 들여다보는 창일 뿐입니다.

### 실행 방법
```bash
claude remote-control
```

### 핵심 특징
- 파일, MCP 서버, 환경 변수, 프로젝트 설정은 모두 로컬 머신에 남아있고, 오직 채팅 메시지와 도구 실행 결과만 암호화된 브릿지를 통해 전달됩니다.
- 터미널을 닫거나 claude 프로세스를 종료하면 세션이 즉시 종료됩니다.

## 2. Spawn Mode: same-dir vs worktree

Remote Control을 활성화하면 폰이나 브라우저에서 새 세션을 생성할 때 어떤 방식으로 만들지 선택해야 합니다.

| 모드 | 설명 | 기본값 여부 |
|---|---|---|
| **[1] same-dir** | 모든 세션이 같은 디렉토리를 공유 | ✅ 기본값 (default) |
| **[2] worktree** | 세션마다 격리된 git worktree 생성 | 선택 사항 |

### 사용 판단 기준
- **same-dir**: 간단한 작업이나 개인 프로젝트처럼, 폰에서 새 세션을 열어도 Mac에서 진행 중인 작업과 같은 맥락을 봐야 하는 경우에 적합
- **worktree**: 같은 레포 안에서 서로 다른 브랜치나 기능으로 나뉘는 독립 작업을 병렬로 진행할 때 적합. 각 세션이 격리된 작업 디렉토리, 격리된 브랜치, 격리된 작업 상태를 가지게 되어 stash나 충돌 없이 작업 가능

### 중요한 제약
Remote Control은 **현재 프로젝트 디렉토리 기준**으로 동작하는 기능이므로, 완전히 다른 레포의 외주 작업까지 하나의 remote-control 세션으로 커버할 수는 없습니다. 레포가 다르면 해당 레포 폴더에서 각각 `claude remote-control`을 별도로 실행해야 합니다.

### 모드 전환
```bash
claude remote-control --spawn=same-dir
claude remote-control --spawn=worktree
```
활성 세션 중에는 `w` 키로도 즉시 전환 가능합니다.

## 3. worktree 모드일 때 PR 병합 및 변경 사항 확인

### PR로 머지되는가?
네, PR로 머지하는 방식이 표준 워크플로우입니다. worktree마다 독립된 브랜치로 작업이 이루어지므로, 각 브랜치는 개별 PR이 되고 리뷰어는 관련 없는 변경 사항 없이 해당 브랜치의 변경만 검토할 수 있습니다.

### 변경 사항 확인 방법

| 방법 | 설명 |
|---|---|
| `git diff` / `git status` | worktree 폴더로 직접 이동해서 확인 |
| `EnterWorktree` 툴 | 같은 세션 안에서 다른 worktree로 바로 전환 가능 |
| PR 생성 요청 | Claude에게 PR 생성을 요청하면 GitHub에서 일반 PR처럼 리뷰 가능 |
| Desktop 앱 UI | 세션별 worktree 상태를 시각적으로 확인 가능 |

세션을 종료할 때, uncommitted 변경사항이나 새 커밋이 없으면 worktree와 브랜치가 자동으로 제거됩니다. 변경 사항이 있으면 Claude가 유지 여부를 직접 물어봅니다.

## 4. 연결 완료 화면 해석

```
Choose [1/2] (default: 1): 1
·✔︎· Connected · Dream · main
    Capacity: 1/32 · New sessions will be created in the current directory
    macbookair-glimmering-engelbart
```

| 항목 | 의미 |
|---|---|
| `Connected · Dream · main` | 연결 성공, 세션 이름 "Dream", 현재 브랜치 main |
| `Capacity: 1/32` | 최대 32개 세션 동시 가능, 현재 1개 사용 중 |
| `New sessions will be created in the current directory` | same-dir 모드 적용 중 |
| `macbookair-glimmering-engelbart` | 이 Mac에 부여된 고유 기기 이름 |

### 접속 방법
1. 터미널에서 **스페이스바** → QR 코드 표시 → 모바일 앱으로 스캔
2. 표시된 URL을 모바일 브라우저에서 직접 열기
3. Claude 모바일 앱의 **Code 탭**에서 연결된 세션 선택

## 5. 실시간 동기화 여부

**결론: 실시간으로 동기화됩니다.**

대화 내용은 터미널, 웹, 모바일 앱 등 연결된 모든 기기에서 실시간으로 동기화되며, 메시지를 터미널, 브라우저, 폰 어디서든 교차로 주고받을 수 있습니다.

### 동작 원리
Remote Control은 클라우드 컴퓨팅이 아닌 동기화 계층입니다. 로컬 Claude Code 프로세스가 Anthropic API에 등록되어 작업을 폴링하며, 다른 기기에서 연결이 오면 API가 로컬 세션과 원격 클라이언트 사이의 메시지를 스트리밍 연결로 중계합니다. 이 과정에서 로컬 머신에는 인바운드 포트가 열리지 않습니다.

### 만약 실시간 반영이 안 될 경우 확인할 사항
1. Mac 터미널 및 claude 프로세스가 열려 있는지 확인 (닫으면 세션 즉시 종료)
2. 네트워크 상태 확인 (Mac이 약 10분간 네트워크에 접근하지 못하면 세션 타임아웃 발생, 재실행 필요)
3. 터미널 하단의 `/rc active` 연결 상태 표시등 확인 (연결이 끊기면 표시가 사라지고 실패 사유 알림이 뜸)
